# 交我录

把检验报告的"录入"变成"核对"。

现在的做法是：先手工把报告上的几十项数字敲进表格，录完再由人翻回去查有没有漏、有没有抄错。
交我录把顺序倒过来——报告一上传，程序先把它读成结构化数据、填进对应的页面，人只需要看
哪一格是红的，点一下回到原图核对。

**它不替医生做判断。** 每个数字都能回到原图的那一行；标绿只说明"这一项读到了、前后不矛盾"，
不说明医学上正常。

## 两种打开方式

**一、在线版（推荐，什么都不用装）**

打开 `https://<你的用户名>.github.io/<仓库名>/`，页面会跳到工作台。

第一次用需要在右上角「设置」里填自己的模型 API Key（存在浏览器本地，不上传）。
默认接的是 DeepSeek 的 `deepseek-flash`；换别的服务商就改接口地址和模型名。

**二、本地版（不用装依赖，但识别仍要联网）**

双击 `start.bat`。它会起一个极小的本地服务并自动打开浏览器，地址是
`http://127.0.0.1:8765/`。关掉黑窗口就停。

本地版省掉的是"部署和安装"，**不是网络**：PDF 拆页、文字层提取、页面渲染都在浏览器本地完成，
但点「开始识别」时，报告页图片仍会由浏览器发送给你自己配置的模型服务商。
所以断网时能打开页面、能看历史结果，但识别跑不了。

需要电脑上有 Python 3（Windows 一般没有就装一下，或者用在线版）。

## 它做什么

1. **按患者上传**——一个患者一次传完他名下所有报告，不用自己先按检查类别分开。
2. **自动归类**——判断这份报告是血常规、生化、出凝血还是病程首页，该填哪一页。
3. **一次识别**——每份报告只读一次，结果缓存；同一份报告不会重复花你的钱。
4. **红黄绿三色**——绿=读到了，红=该有的没有，灰=这一页本来就没这一项，黄=**同一次就诊**的两份报告对不上（不同日期的差异不算矛盾，会进时间轴对照）。
5. **回到原图**——点任意一行，调出它出自的那份报告那一页。
6. **导出**——CSV 直接进表格软件。

## 页面和指标都能改

侧栏「指标与页面」里可以自己加指标（代号、名称、单位、参考范围、同义词）和页面（这一页要录哪几项）。
存在的浏览器本地存储里，换台电脑就没有了——科室自己的字段表，不该存在别人服务器上。

**默认没有任何必填项。** 哪一页必须填全，自己在侧栏勾"必填"，不勾就不会标红。
要精确到某一项，在「指标与页面 → 指标库」里勾那一行前面的"必填"；侧栏那个勾只是整页批量。

**页面组**：把常用的几个页面存成一组（比如"常规页面组"），点一下就把组里的页面全勾上，
并带上组里预设的必填项；取消组，预设也跟着失效。

## 一句话生成质控任务

「本批质控规则」里有一句话入口：用中文说清这次要整理什么、哪些项目必须齐全，例如

> 本次整理病案首页、血常规和肾功能；姓名、血红蛋白、肌酐为必填，其他指标有就整理。

模型把它翻译成"选哪几个页面、哪些指标必填"，然后：

- **本地先校验**：只认指标库里已有的页面和指标，模型编的 ID 一律丢掉并列出来；
- **先给你看**：整理页面、必填指标、没法自动落实的要求（比如"顺便判断有没有白血病"）都列在预览里；
- **你点确认才生效**：确认后替换本批规则，顶部摘要和勾选同步变；取消则原规则一点不动；
- **不会自动上传、不会自动识别**，也不会替你创建指标或医学规则。

配置只保存在本机浏览器里，刷新后仍在；换台电脑要重新配置或用「指标与页面 → 导出配置」搬过去。

## 数据存在哪里

- **指标、页面、页面组、必填设置**：浏览器 `localStorage`，换台电脑就没有了——科室自己的字段表，不该存在别人服务器上。
- **当前任务（患者、报告、识别结果）**：浏览器自带的 **IndexedDB**，改动后 700 毫秒自动落盘，**保留 24 小时**。
  不小心关掉页面，重新打开会自动恢复上次的任务（包括已识别的结果），提示"已恢复上次的任务"。
- 点「清空本次任务」会同时删掉这份本地存档。超过 24 小时的存档在下次打开时自动丢弃。

报告图片会以压缩后的形式一并存在这个本地库里（长边 1500 像素）。它只在这台电脑上，
但如果你用的是公用机器，用完请点「清空本次任务」并清掉浏览器数据。

## 隐私与数据流（说准确）

- **在线访问和 AI 识别都需要联网。** 本地双击 `start.bat` 只是把页面发给浏览器，不代表模型识别是离线的。
- **PDF 拆页、文字层提取、页面渲染在浏览器本地完成**；但点「开始识别」后，报告页图片会由浏览器
  发送给**你自己配置的模型服务商**，由对方完成识别。
- **报告不经过本项目作者的服务器**（本来也没有服务器），但**不等于任何第三方都收不到**——
  数据确实会发给你所选的服务商，这一点请按你所在机构的规定评估。
- **"导出时隐藏身份信息"只作用于导出文件**，不改变"发给模型前"的图片内容。
  需要更严格时，请在上传前就把姓名等区域裁掉。
- 没有后端、没有账号、没有上传中转：任务数据要么在内存里，要么在这台电脑的浏览器存储里。
- 公用电脑使用后请点「清空本次任务」并清理浏览器数据。
- **医院真实部署还需要授权、安全评估和模型服务合规审核**，这不是一个学生作品能替代的流程。
- 导出的表格勾上"导出时隐藏身份信息"后，姓名、身份证、电话、其他联系方式、地址、住院号都会被替换成掩码
  （报告文件名里如果带着姓名，也会一起替换）；关掉这个开关则按原始结果导出。
- 演示与测试用的是程序生成的合成报告，不含任何真实患者信息。

## 目录

```
app/            前端（原生 HTML/CSS/JS，无构建步骤）
  js/app.js        工作台主逻辑
  js/model.js      模型调用
  js/indicators.js 指标与页面的默认值
  vendor/          PDF.js（本地打包，不走 CDN）
server.py       本地版用的静态文件服务（Python 标准库，约 150 行）
start.bat       Windows 双击入口
tools/          生成合成报告等开发脚本
test/           端到端测试（真实浏览器 + 真实模型）
```

## 开发

没有构建步骤，改完刷新页面即可。测试用 Node 驱动 Chrome：

```bash
node test/e2e.mjs
```

需要先在 `secrets/ark_api.txt` 放一个模型 API Key（该目录不入库）。
